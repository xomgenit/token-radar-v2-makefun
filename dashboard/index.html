The model, with its error on the table

log10(market cap) = a + b·log10(TVL) + d·log10(age) + category offsets, fitted by least squares on the snapshot's traded protocols. Growth is fitted on the residuals and held at zero — the snapshot does not price it. Two held-out tests run before any value is shown; the dashboard prints both multiples, not just the fit.

The 758 audit — every protocol accounted for

The snapshot holds 758 protocols. Each one is in exactly one bucket below; the counts sum to 758, and the watchlist is covered 40 of 40. Wrapped, staked and bridged products of tokens that already trade are never ranked as launches.

    Token odds — the peers' record

    Odds are the share of protocols in the same category and age band that already record a token, shrunk toward the global rate. They are a base rate, not a prediction of whether or when a token is issued. Expected value is implied value × odds.
